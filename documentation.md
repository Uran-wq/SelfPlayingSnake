## Игровой движок (`environment/snake_env.py`)

Класс `SnakeEnv` — среда, в которой живёт змейка. Не зависит от типа управляющего агента.

### Внутреннее состояние

| Поле | Тип | Описание |
|------|-----|----------|
| `snake` | `list[(row, col)]` | Список позиций тела. `[0]` — голова |
| `food` | `(row, col)` | Позиция еды |
| `grid_size` | `int` | Размер поля (по умолчанию 20) |
| `direction` | `Action` | Текущее направление движения |
| `score` | `int` | Счёт (количество съеденной еды) |
| `done` | `bool` | Игра окончена |

### Метод `step(action)`

1. Проверяет, не пытается ли змейка развернуться на 180°
2. Вычисляет новую позицию головы по вектору направления
3. Проверяет коллизии: вылет за границу или врезание в себя → `done=True`, награда `-10`
4. Если новая голова совпала с едой → змейка растёт (+1 очко, награда `+10`)
5. Иначе — удаляет хвост (тело не растёт)
6. Возвращает `(наблюдение, награда, done, инфо)`

### Награды

| Событие | Награда |
|---------|---------|
| Съел еду | `+10` |
| Столкновение (стена/себя) | `-10` |
| Выживший шаг | `+0.1` |

### Два типа наблюдений

- **`_get_observation()`** — тензор `20×20×3` (каналы: голова, тело, еда). Используется для визуализации.
- **`get_simplified_observation()`** — вектор из 12 чисел. Используется нейросетью.

## Implementation 1 — Гамильтонов цикл

**Идея:** Построить путь, проходящий через каждую клетку поля ровно 1 раз и замыкающийся в цикл. Змейка просто следует по этому пути и никогда не врезается.

### Построение цикла

Алгоритм `build_hamiltonian_cycle` строит путь для чётного поля:

```
Строка 0:  (0,0) → (0,1) → ... → (0,19)       вправо
Строка 1:  (1,19) → (1,18) → ... → (1,1)       влево (пропуская col=0)
Строка 2:  (2,1) → (2,2) → ... → (2,19)        вправо
Строка 3:  (3,19) → (3,18) → ... → (3,1)       влево
...
Строка 19: (19,19) → (19,18) → ... → (19,1)    влево
Столбец 0: (19,0) → (18,0) → ... → (1,0)       вверх
Замыкание: (1,0) → (0,0)
```

Каждая пара соседних клеток в этом списке — смежные (сверху/снизу/слева/справа), включая замыкание `(1,0) → (0,0)`. Всего 400 клеток (20×20).

### Агент

- На каждом шаге берёт текущую позицию головы
- Смотрит в `cycle_map` какая клетка следующая
- Вычисляет направление (UP/DOWN/LEFT/RIGHT) и возвращает действие

### Результат

Змейка гарантированно не умирает. Ест еду когда цикл проходит через неё. Средний счёт ~4 за 800 шагов.

## Implementation 2 — Отклонения от цикла

Базовая логика та же, что и в Implementation 1, но с тремя источниками поведения:

```python
if random() < epsilon:              # ~10% — случайное безопасное действие
    action = random_safe_action()
elif food_is_nearby():              # еда близко (< 3 клеток) — жадный поворот
    action = greedy_towards_food()
else:
    action = next_on_cycle()        # иначе — следуем циклу
```

### Компоненты

- **`random_safe_action()`** — проверяет все 4 направления, отбрасывает разворот на 180° и коллизии, выбирает случайное из безопасных
- **`greedy_towards_food()`** — из безопасных направлений выбирает то, которое минимизирует Манхэттенское расстояние до еды

### Результат

Часто умирает (отклонения приводят к коллизиям), но иногда находит еду быстрее. Средний счёт ~2.5.

## Implementation 3 — Нейросеть (DQN)

### Алгоритм

**Deep Q-Network** — агент учится на опыте, предсказывая «ценность» каждого действия.

### Входные признаки (12 чисел)

| Признак | Диапазон | Описание |
|---------|----------|----------|
| `danger_ahead` | 0/1 | Опасность прямо |
| `danger_left` | 0/1 | Опасность слева |
| `danger_right` | 0/1 | Опасность справа |
| `food_dx` | -19..19 | Горизонтальное расстояние до еды |
| `food_dy` | -19..19 | Вертикальное расстояние до еды |
| `head_dx` | -1/0/1 | Текущее горизонтальное направление |
| `head_dy` | -1/0/1 | Текущее вертикальное направление |
| `distance_to_food` | 1..38 | Манхэттенское расстояние до еды |
| `dir_onehot(4)` | 0/1 | Текущее направление one-hot |

### Архитектура нейросети

```
Input(12) → FC(128) → ReLU → FC(128) → ReLU → FC(4) → Q-values
```

4 выхода — Q-ценность для каждого действия (UP, DOWN, LEFT, RIGHT). Выбирается действие с максимальным Q.

### Обучение

| Компонент | Описание |
|-----------|----------|
| **Replay Buffer** | Буфер на 10,000 переходов `(s, a, r, s', done)`. Из него берутся случайные батчи по 64 |
| **Target Network** | Копия основной сети, обновляется каждые 1000 шагов. Стабилизирует обучение |
| **Epsilon-greedy** | ε = 1.0 → 0.05. С вероятностью ε агент берёт случайное действие (исследование) |
| **Loss** | MSE между `Q_predicted` и `Q_target = reward + γ * max(Q_target_net(s'))` |

### Цикл одного эпизода

```
1. env.reset() → начальное состояние
2. Пока не done:
   a. Агент выбирает действие (epsilon-greedy)
   b. env.step(action) → (next_state, reward, done)
   c. transition.store(buffer)
   d. Раз в шаг — buffer.sample(64) → обновление весов
   e. Раз в 1000 шагов — копирование весов в target_net
3. Сохранение модели в models/dqn_snake.pt
```

### Гиперпараметры

| Параметр | Значение |
|----------|----------|
| Learning rate | 1e-3 |
| Gamma (discount) | 0.99 |
| Epsilon start/end | 1.0 / 0.05 |
| Epsilon decay | 0.995 |
| Buffer size | 10,000 |
| Batch size | 64 |
| Target update freq | 1,000 шагов |
| Max episodes | 5,000 (по умолчанию) |

## Запуск

### Без визуализации (консоль)

```bash
# Только Implementation 1
python main.py --impl 1 --episodes 20

# Только Implementation 2
python main.py --impl 2 --episodes 20

# Обучение DQN + оценка
python main.py --impl 3 --episodes 200 --train

# Загрузка обученной модели
python main.py --impl 3 --no-train --model-path models/dqn_snake_final.pt

# Все три реализации + сравнение
python main.py --episodes 100
```

### С визуализацией (pygame)

```bash
# Implementation 1
python main.py --visual --impl 1 --visual-episodes 3 --fps 20

# Implementation 2
python main.py --visual --impl 2 --visual-episodes 3 --fps 15

# Implementation 3 (нужна обученная модель)
python main.py --visual --impl 3 --visual-episodes 3 --fps 15 --no-train --model-path models/dqn_snake_final.pt
```

### Параметры

| Флаг | Описание | По умолчанию |
|------|----------|-------------|
| `--impl` | Какую реализацию запускать (0=все) | 0 |
| `--grid-size` | Размер поля | 20 |
| `--episodes` | Количество эпизодов | 100 |
| `--train` | Обучать DQN | True |
| `--no-train` | Загрузить модель | — |
| `--model-path` | Путь к модели | models/dqn_snake.pt |
| `--epsilon` | Epsilon для Impl2 | 0.1 |
| `--visual` | Визуализация pygame | False |
| `--visual-episodes` | Эпизодов для визуализации | 3 |
| `--fps` | Кадров в секунду | 10 |
